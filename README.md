# NovaCalc PWA

Kalkulator PWA modern dan offline-ready.

## Fitur
- Tampilan premium glassmorphism
- Responsive untuk HP
- Standard & Scientific mode
- Riwayat perhitungan tersimpan di browser
- Tombol copy hasil
- Dark / Light theme
- Keyboard support
- Install sebagai aplikasi
- Service Worker untuk offline

## Deploy ke GitHub Pages
Upload semua file dalam folder ini ke repository GitHub, lalu aktifkan:
**Settings → Pages → Deploy from a branch → main → /(root)**

Setelah website HTTPS aktif, buka dari Chrome Android lalu pilih **Install app / Tambahkan ke layar utama**.
